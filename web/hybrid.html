What has the room seen?

Set XAI_API_KEY before starting the server to enable Grok.
Identity rule: Grok describes visible objects and supplies a conservative visual signature. Matching signatures can merge repeat sightings, but this is not proof that two identical-looking objects are the same physical instance. The local tracker remains authoritative for registered desk objects.
